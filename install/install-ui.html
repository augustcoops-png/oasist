Solana Node Installer

Pick your platform — copy and run the one-line command.

Run in your terminal

bash <(curl -sSfL https://raw.githubusercontent.com/augustcoops-png/oasist/main/install/install-node-linux.sh)

Supports Debian/Ubuntu, Fedora, Arch, Alpine, openSUSE.
Installs: system deps · Node.js · Rust · Solana CLI

Run in your terminal

bash <(curl -sSfL https://raw.githubusercontent.com/augustcoops-png/oasist/main/install/install-node-macos.sh)

Installs Homebrew if missing, then Node.js (nvm), Rust & Solana CLI.
Intel and Apple Silicon (M1/M2/M3) supported.

Run in PowerShell (Administrator)

Set-ExecutionPolicy Bypass -Scope Process -Force; Invoke-Expression ((New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/augustcoops-png/oasist/main/install/install-node-windows.ps1'))

Or download install-node-windows.bat and run as Administrator.
Installs: Git · VS Build Tools · LLVM · Node.js · Rust · Solana CLI

Run inside Termux on Android

curl -sSfL https://raw.githubusercontent.com/augustcoops-png/oasist/main/install/install-node-termux.sh | bash

Opens Termux → paste → press Enter.
Installs: Termux packages · Node.js · Rust · Solana CLI
